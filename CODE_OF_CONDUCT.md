# Code of Conduct

## Scope

This code applies to every space the project uses: issues, pull requests,
discussions, releases, commit messages, and review comments.

## Expected behavior

- Discuss behavior and code, not people.
- Assume good faith, and ask a question before assuming a mistake.
- Keep reports reproducible and free of secrets, customer names, and private
  paths.
- Accept that scope decisions belong to the maintainer.

## Unacceptable behavior

- Harassment, insults, or discrimination of any kind.
- Publishing another person's private information without permission.
- Deliberately disruptive behavior, including spam and repeated off-topic
  comments.
- Pressing for a fix, a timeline, or a policy change after the maintainer has
  answered.
- Sharing source code, configuration, or customer material you are not allowed
  to share.

## Reporting

Report unacceptable behavior privately through GitHub, either through the
maintainer's profile contact or through
[private vulnerability reporting](https://github.com/SorenHJohansen/SattLint/security/advisories/new)
if the report contains sensitive material. Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, close issues, lock threads, or
block accounts. Enforcement decisions are final. This project has one
maintainer, so there is no separate appeals board.
